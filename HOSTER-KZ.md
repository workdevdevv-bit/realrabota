# Публикация на Hoster.kz

Проект собирается в полностью статический сайт. Node.js, Wrangler и постоянно работающий процесс на хостинге не требуются.

## Сборка

```bash
npm ci
npm run build:hoster
```

После успешной сборки появится папка `httpdocs`. Загрузите **её содержимое** в каталог `/httpdocs` вашего домена на Hoster.kz через файловый менеджер Plesk или FTP.

В корне хостинга должны находиться `index.html`, `.htaccess`, папка `_next` и изображения сайта.

## Локальная проверка готовой сборки

```bash
npm start
```

Команда запускает только локальный предпросмотр содержимого `httpdocs`; на Hoster.kz она не используется.
